A program that writes a one-star review of Monday, as if Monday were a restaurant — 23 words on a single line, straight to `/output/entry.txt` — for make.fun's "One Star for Monday" bounty. A tired diner's complaint: a draughty table, lukewarm coffee with a side of dread, and a bill that eats the whole weekend.

## Run it

```sh
node main.ts && cat /output/entry.txt
```
